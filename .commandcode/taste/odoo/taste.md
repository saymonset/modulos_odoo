- In the Docker-based Odoo setup with bind mounts, Python `.pyc` bytecode caching is a separate problem from view XML caching. Even when `.py` files are already visible inside the container via bind mount, the cached `.pyc` files may still load stale bytecode. To reliably pick up Python model changes: either (a) clear `__pycache__` directories (`rm -rf .../__pycache__`) inside the module and then restart only the web container (`docker restart odoo-19-web-<name>`), or (b) use Odoo's Technical → Database → Clear Cache — but Option (a) is more reliable. Confidence: 0.80

Always clear `__pycache__` first, restart the container, then run the CLI upgrade. Confidence: 0.70
